BUILD METHODS:
==============

1. Automated Script
   .\build.bat

2. Visual Studio IDE (Open Folder)
   File → Open → Folder → Select verible-preprocessor-standalone

3. Visual Studio IDE (Solution)
   Generate .sln with cmake, then open in VS

4. Command Line (MSBuild)
   cmake .. && cmake --build . --config Release

5. Command Line (Ninja)
   cmake .. -G "Ninja" && ninja

QUICK START EXAMPLE:
====================

# One-time setup (15 minutes)
git clone https://github.com/Microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
C:\vcpkg\vcpkg integrate install
C:\vcpkg\vcpkg install abseil:x64-windows winflexbison:x64-windows

# Build (every time, 2 minutes)
cd verible-preprocessor-standalone
.\build.bat

# Done! Run example
build\Release\preprocessor_example.exe

INTEGRATION:
============

Three ways to integrate into your Windows project:

1. Add as subdirectory in CMake:
   add_subdirectory(verible-preprocessor-standalone)
   target_link_libraries(MyApp PRIVATE verilog_preprocessor)

2. Install and link:
   cmake --install . --prefix C:\MyLibs
   (then link against installed .lib)

3. Direct linking:
   Add .lib to linker, add api\ to include path
